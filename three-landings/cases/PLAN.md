# calla — план копирования дизайна (референс: видео 2026-11-06 23-43-51.mp4)

Референс — одностраничное портфолио дизайнера с сайта-галереи «free for copying».
Цель этапа 1: повторить вёрстку, ритм, палитру и анимации 1:1.
Этап 2 (потом): дополнить своим.

## 0. Что копируем, а что заменяем

Копируем: сетку, типографику, палитру, порядок секций, scroll-анимации, 3D-сцены, микро-UI.

Заменяем обязательно (это чужое, а не дизайн):
- имя дизайнера, монограмма «Aj», подпись во вкладке → свои;
- проекты EVOK / Nuraform / Frank's / Truekind / KIN / Resolute → **свои лендинги из этой папки**: fleur, sense, kyoto, norma, opara, folio (скриншоты уже есть в `assets/`);
- фото людей, коллажи, ветки, плейбук-работы → свои / сгенерированные;
- мини-игра в ретро-компьютере (в оригинале — известная игра-головоломка) → своя простая игра (например, «поймай лепестки»), не клон чужой.

```css
--sky: #a9c8e4;        /* эллипс, небо */

--lilac: #b48fd6;      /* бейдж контакта */
```

Шрифты (self-host в `assets/fonts/`, как остальные лендинги):
- display кондэнсд: **Anton** (ближе к оригиналу — Druk Condensed Super, платный);
- рукописный курсив: **Pinyon Script**;
- курсив-сериф для абзацев: **Libre Caslon Text Italic** или **Cormorant Garamond Italic**;
- мелкий капс/UI: **Inter** (или уже подключённый Golos Text — для кириллицы);
- «VISUAL IDENTITY»: **Archivo** (широкий).

Нужна кириллица → проверить покрытие; Anton и Pinyon без кириллицы, для RU-версии замена: Oswald 700 (уже есть) + Marck Script / Caveat.

## 3. Стек

Как у соседних лендингов — чистые HTML/CSS/JS, без сборки:
- `cases/index.html`, `cases/calla.css`, `cases/calla.js`, `cases/scene.js` (3D);
- **Three.js r160** (ES-модуль с jsDelivr, версия пиннится);
- **GSAP 3.12 + ScrollTrigger** — pin, scrub, reveal;
- **Lenis 1.1** — плавный скролл;
- раздаётся существующим `server.mjs`.

3D без скачивания чужих моделей — процедурно:
- калла = `LatheGeometry` (профиль воронки) + отогнутый лепесток (деформация вершин) + стебель `TubeGeometry` по кривой; материал `MeshPhysicalMaterial` (clearcoat, sheen) + HDR-окружение (`RoomEnvironment`);
- ретро-ПК = набор скруглённых боксов (`RoundedBoxGeometry`), экран — `CanvasTexture`, в которую рисуется мини-игра;
- линзы и сетки секции 10 — 2D (SVG/CSS 3D), не WebGL.

## 4. Фазы

1. **Каркас** — папка, шрифты, токены, `base` reset, заглушки картинок, подключение библиотек, курсор и зерно.
2. **Статичная вёрстка 11 секций** (desktop 1440, затем 768 и 375) — сверка с кадрами из видео.
3. **Скролл-анимации** — Lenis + ScrollTrigger: смена фона hero→слива, reveal строк манифеста, scrub перекраски абзаца, marquee, sticky «Services/Provided», горизонтальный Playbook.
4. **Hero 3D** — каллы, свет, вращение от курсора, слой поверх карточки с эллипсом.
5. **Шоурил (сек. 4)** — pinned-таймлайн: дуга → прямоугольник, смена 4 слайдов, лента → круговой коллаж.
6. **Featured Projects** — 3D-тилт карточек по скроллу, вращающиеся бейджи, свои 6 проектов.
7. **Ретро-ПК + мини-игра**.
8. **Полировка** — `prefers-reduced-motion` (без pin/3D, статичные кадры), мобильный фолбэк 3D (картинка вместо WebGL), lazy-load, LCP < 2.5 с, 60 fps на скролле.
9. **Проверка** — превью в браузере, скриншоты секций рядом с кадрами видео, консоль без ошибок; добавить карточку в `index.html`.

Критерий «готово» для этапа 1: каждая из 11 секций по раскладке, цветам и поведению узнаётся рядом с кадром видео; контент — свой; работает на 1440 / 768 / 375; reduced-motion не ломает страницу.
